# 词间 Cijian

面向英语学习者的本地优先背单词软件，适合四级、六级备考及日常词汇积累。核心流程：导入词库 → 学习新词 → 复习 → 自测 → 错词巩固。

## 下载与安装

安卓APK附件尚待上传，当前尚无可用的公开安装包下载。[查看发行版页面](https://github.com/xiaohaoyu14/cijian/releases)。源码现已公开，可按下文说明构建。

仅支持arm64-v8a、64位安卓设备，最低Android7/API24。原签名旧版本可以直接覆盖安装，勿卸载或清除数据。iOS版尚未完成，APK不能用于iPhone。

## 软件有什么功能

- 内置四级4543条、六级5617条、SAT8810条；跨库去重共18735个独立词条，首页可先选词库。
- 今日学习、每日新词目标、学习暂停恢复；学完一批新词即可进入同批即时复习。
- 官方FSRS间隔复习、四档回忆反馈、撤销评分、到期计划、分批和记忆档案。
- 个人考试：50词、100词或自定义；四种题型及混合模式；固定试题快照、计时恢复、成绩和错词巩固。
- Piper en_US-lessac-high离线美式女声，点击英文或喇叭实时朗读；无需系统TTS或Google服务。
- CSV/TXT/ZIP词库导入、预览与冲突处理，保留个人学习记录；图片、例句、音频、笔记和收藏。
- 学习统计、50条分页及全库搜索、完整备份恢复；恢复前自动保留本机保护备份。
- 可配置的手动加密云存档；需要自行部署服务，不提供预置公共云服务。

默认无需注册，词库和个人记录保存在设备本地；已导入内容、学习和考试可离线使用。云端上传和恢复需要网络。

## 源码与构建

React + TypeScript + Vite + Capacitor6；数据使用IndexedDB。请先读[源码包说明](源码包说明.md)、[工作日志](工作日志汇总.md)及[项目约定](AGENTS.md)。模型与AAR未放入仓库，用scripts/prepare-piper.py下载锁定版本；签名私钥不公开。下方保留完整开发、运行、数据目录与版本说明。

## 单词喇叭与Piper离线语音

词库列表、单词详情、学习卡和合适的考试位置增加喇叭。只增加朗读，不改变原有查看答案与评分流程。正式考试的中文提示题不会通过喇叭泄露隐藏英文答案；交卷后的报告可点读。

点击喇叭使用**en_US-lessac-high美式女声**实时推理，不调用安卓系统TTS、Google服务或在线语音。设置可开关发音，首次使用显示“语音引擎加载中”。原来词库自带的音频播放器仍独立保留；点读按钮固定走Piper。图文示例包中的示例媒体不作为内置4543词的点读缓存。

模型经用户确认替代官方不存在的amy-high。配置来自原始Piper配套JSON，不是自编参数；high为模型档位，原生采样率22,050Hz。

模型完整路径：`android/app/src/main/assets/piper/en_US-lessac-high/`，其中必须有ONNX、config.json、tokens.txt、espeak-ng-data/及files.json。当前模型与AAR已就绪，哈希见`models.lock.json`。

原生单例引擎在后台线程解包校验并执行CPU推理，最多2线程，将输出转为16-bit PCM后用AudioTrack直接播放。无逐词MP3缓存。固定**sherpa-onnx 1.13.3**：真实测试发现2.x移除了本方案依赖的内置音素前端，不能仅凭编译成功随意升级。

模型ONNX约114MB，全部模型资源约132MB；APK约162MB，首次解包另需私有空间。模型仅加载一份，关闭发音会停止播放与待播任务，已加载模型在Activity销毁时释放。手机RAM峰值、耗电和实际发音仍需真机测试。

## 本地数据与旧版本

完整版继续使用原数据库`cijian-local-v1`（版本2），`state/root`保存规范化业务实体，`media`独立保存媒体内容，日常按当前词条读取。兼容第一版版本1内嵌媒体的迁移。完整备份读取媒体后输出ZIP，不把静态Piper模型重复塞进每次个人备份。

2.0.0精简版的`cijian-txt-v1`未删除，也不替代完整数据库；如在精简版导入了其他TXT，可以用原TXT通过恢复后的导入入口补入。不要卸载或清空应用来“恢复界面”，以免删除旧记录。

同包名、同签名，versionCode升为15，支持在此前版本上覆盖安装的静态条件。真机覆盖升级尚待验证，升级前可在旧版设置导出完整备份。

## 构建与运行

环境：Node.js24、Java17、Python3.10+、Android SDK platform34、build-tools35.0.0、Gradle8.9、AGP8.7.3。设置JAVA_HOME和ANDROID_HOME。

```powershell
npm ci
# 当前目录已有模型；新克隆缺失时再下载：
python scripts/prepare-piper.py
python scripts/verify-piper-assets.py
pwsh -NoProfile -File scripts/build-apk.ps1
# Maven/Gradle依赖已缓存时可加 -Offline
python scripts/verify-apk.py
```

构建会执行网页构建、模型校验、Capacitor同步、Release构建、16KB zipalign、签名校验。签名密钥与口令仅保存在`.signing/`，勿提交或公开；升级必须复用密钥并增加versionCode。

电脑运行`npm run dev`，打开localhost:5173，可验证完整学习功能。Piper点读只在安卓原生运行，网页不会偷偷回退到系统/在线语音。`npm run build`后可用`npm run preview`检查生产网页；不同端口/浏览器有独立本地数据。

## 词库格式与备份限制

原CSV/ZIP导入、共享导出和冲突选择全部恢复。TXT为新增导入格式：每行“单词  词性  中文释义”，支持UTF8/BOM及带BOM的UTF16LE，清洗空行、注释、异常和重复行，导入前预览；异常行不覆盖原数据。

CSV要求word、meaning_zh，其他音标/词性/搭配/例句/标签可选。ZIP根目录需manifest.json、entries.json，可带images/、audio/。内容更新与个人记录分开，过去考试按快照显示。

每次词库导入最多10000词；ZIP压缩50MB、解压100MB、单文件10MB、最多5000文件。完整备份同受ZIP限制，记录JSON最多10MB。图片新增会自动压缩，媒体缺失不影响文字学习。更大数据量分表/分卷备份尚未实现，不能宣称无限容量。
