# 词间3.2.2：新词学完即复习

## 行为

新词学完一轮后，自动保存同批「新词即时复习」队列，不必等待FSRS到期。完成页点击「立即复习这批新词」；返回首页也可以点「开始复习」或「继续上次学习」。复习先隐藏答案，真实评分继续由原FSRS处理。

每批即时复习、原到期任务和不同词库分别保存，互不覆盖。支持暂停、重开、撤销及完整备份恢复；完成后不会无限重复生成同一批。撤销新词最后一次评分会撤回待开始的即时队列。原三库、选库、考试、媒体、笔记、统计与Piper全部保留。

「即时复习」属于额外的一轮主动回忆，不是伪造到期。准备/打开队列不改卡片、到期时间或日志，只有四档真实反馈才更新FSRS；每日到期指标继续仅统计真正到期卡片，首页另行提示即时复习剩余数。每批仅生成一次，做完后回到正常到期计划；忘记的词仍按官方短期重学时间再次安排。

旧版已有完成的新词会话，点击开始复习时也可生成这一批即时队列；不会根据历史日志补造其他旧批次。

## 实现

- src/learning.ts：prepareNewReview生成待开始队列，pendingReview统一恢复，sessionKey按来源批次分开存储。selectStudy保持旧到期任务、各库和各批进度。
- src/study-actions.ts：新词评分完成时同一事务保存队列，撤销完成评分时撤回该来源的待开始队列；保留原写入游标与卡片检查。
- src/study.tsx：完成页立即复习入口、即时复习标题与提示；继续沿用隐藏答案、300ms揭晓动画、四档评分与撤销。
- src/overview.tsx、src/reviews-ui.tsx：首页与计划页提示、恢复入口。
- src/types.ts、src/library.ts：StudySession可选newReviewOf；旧备份无需此字段，新的即时队列参与完整备份校验恢复。
- tests/new-review.spec.ts：5项新增回归。
