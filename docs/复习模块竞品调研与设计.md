调研日期：2026-10-29。当前可运行版本：3.1.1。本轮完成资料核对与设计，不改应用代码或重打APK。以用户“原有功能不动，只改善复习模块”为边界。

## 1. 调研依据和限制

## 2. 对“艾宾浩斯曲线”的产品判断

遗忘曲线、间隔效应是研究基础，不能等同于所有单词统一采用“第1、3、7、15天复习”。墨墨的[记忆科普](https://www.maimemo.com/pages/memory-science-popularization/?open_by=markji)也区分了早期遗忘研究与之后的间隔重复、记忆建模。

当前软件已使用锁定版本ts-fsrs 6.0.0 / FSRS-7，根据单词状态、反馈和真实经过时间计算下次日期。现阶段的问题主要是复习计划缺乏解释和可视反馈，并不是缺少调度器。方案保留它，默认90%目标保持率不变，仍说明这是调度目标而非效果保证。

实现参考：[ts-fsrs官方仓库](https://github.com/open-spaced-repetition/ts-fsrs)。竞品公开说明不等于本项目使用了竞品算法。

## 3. 建议的复习模块

### 3.1 今日复习任务卡

在当前所选词库下展示：

- 现在到期多少词，其中逾期多少、需要短期重学多少。
- 今天已经复习多少个不同词，同时单列反馈次数，避免同词重学多次被当成多个词。
- 今天稍后还会到期多少词，下一个到期时间。
- 入口：开始/继续复习、查看复习计划。保持现有“学习新词”入口与每日20词设置。

所有数字从真实卡片和未撤销日志产生，无记录时显示空状态。四级、六级、SAT沿用现有词库选择；共有词不重复建卡。

### 3.2 复习队列与负担控制

- 以到期时间为准，不把未到期词强行塞进计划。
- 在到期词中优先处理短期重学和风险较高/逾期词，排序依据应显示并可测试；最终采用哪种排序要与现有FSRS可提供的信息一致。
- 分为每轮20词、50词或全部。分批只改变每轮长度，不隐藏积压，不把“完成一轮”写成“今天全部完成”。
- 忘记后进入FSRS短期重学。达到调度时间再出现，结束本轮时提醒还有哪些短期任务。
- 复习多时建议减少今日新词，用户主动选择；不擅自改掉现有20新词设置，也不强制禁止学新词。
- 暂停、重开、撤销继续支持；暂停不会停止现实时间，不重置学习历史。

### 3.3 计划页：回答“多少天前的词今天要复习”

提供两个互补视角：

1. 今日到期来源：按首次学习日期查看今天到期的词，例如昨天学的、2—6天前学的、7—29天前学的、更早学的；每词还能看到最近一次复习日期。
2. 未来7天到期分布：显示目前已有卡片的到期数量，点击可查看对应词。

这些日期分组只是查看方式，绝不拿分组替代调度间隔。未来分布注明“不含之后新学和再次遗忘产生的新增任务，会随实际反馈变化”，不显示虚构的精确预测。

### 3.4 单词记忆档案：回答“我到底记牢没有”

优先显示可核实事实：初学日期、复习次数、跨日成功次数、最近的回忆表现、遗忘次数、上次间隔与下次到期时间。只有实际模型可算且含义清楚时才增加预计保持情况，并明确“模型估计”。

可设“初学 / 巩固中 / 较稳固 / 待重学”作为用户容易理解的进度标签。“较稳固”综合跨日成功和记忆稳定性，其阈值属于公开的产品展示规则，不冒充普适记忆定律，不干预FSRS调度，也不永久退出复习。

不承诺“背3次/7次就彻底牢固”。当天连续点击多次记得，不能与隔几天仍独立回忆正确等价。考试的选择题正确率也不能直接替代回忆成功。

### 3.5 复习操作与结束反馈

- 先看英文独立回忆，答案默认隐藏；查看答案后保留原四档反馈。
- 不能照搬墨墨“模糊”的含义：本软件“有点费力”仍指正确但困难；回忆错误必须选忘记，保证FSRS日志含义不变。
- 查看答案后展示各反馈对应的预计下次时间，来自真实FSRS预览，不手写固定天数。
- 完成本轮展示：处理多少个词、忘记/费力/记得/熟悉分布、当前剩余到期数量、下一批与短期重学入口。
- 额外看词、现有自测保持独立；不把浏览答案、播放发音、选择题答对直接记入FSRS。

## 4. 改动边界

只增加/改善复习入口、计划页、复习过程与结果说明。保留三个词库、词库导入导出、首页词库选择、新词学习、考试、原统计、笔记收藏、图片、Piper点读、设置与完整备份恢复。现有卡片和日志继续使用，不清库，不重置FSRS，不改语音引擎。

调度器依赖不升级，已有依赖锁不变。可视化由真实数据派生；新用户没有学习日志时显示尚未形成复习计划，而不是内置模拟记忆曲线。

## 5. 后续实施与验收

先实现任务与计划解释、分批复习、单词记忆事实，再完善曲线可视化。只有数据量和模型接口足够支持时才展示个体记忆预测。

关键测试应包括：所选词库过滤与共享词去重、分钟级/跨天到期边界、逾期不被漏掉、每日不同词数与反馈次数区分、同日重复不计跨日巩固、撤销恢复计划、分批仍显示真实剩余任务、暂停/重开恢复、预测不改数据、考试不改FSRS、升级后旧记录与备份完整保留。
