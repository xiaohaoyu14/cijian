## 实现与边界

- src/use-page-motion.ts：仅在路由或首次加载状态改变时，使用Web Animations API对同一main表面做一次220ms、16px滑入/淡入，按页面次序选择方向。不上双份旧页面，不增加按词库大小增长的动画循环，也不用强制布局重启动画。
- 不以页面动画key重新挂载表单。评分、打字、保存引发的数据更新不重启动画；用户输入无业务等待。结束后fill为默认none，无持久transform/will-change，无额外常驻图层要求。缺少animate时直接展示页面。
- src/main.tsx：点击捕获阶段结束转场，事件目标已确定，随后原点击业务正常执行。键盘按键或触摸滚动取消时同样可结束动效。不要改回pointerdown立即取消transform，会让小按钮在按下后移出触点，导致点击失效。
- src/style.css：button与导航按压0.95缩放；仅启用按钮有按压效果；键盘focus-visible有轮廓。shell的overflow-x:clip防止移动中的页面制造横向滚动，不建立额外滚动容器。
- 系统prefers-reduced-motion下不启动页面动画，动态开启偏好会取消当前转场；按压缩放与过渡关闭。复习答案原有减少动画支持保留。
- tests/page-motion.spec.ts：3项真实界面回归，主动冻结动画以检查转场期间输入、弹窗、小按钮、连续切换、返回、减少动画、松手恢复、手机无横向溢出和评分不重复挂载。正常完成时的释放另由生产构建检查。
