# 词库格式与导入规则

## CSV

UTF-8 编码（支持 BOM）。必须有表头；标准 CSV 引号、逗号转义和换行由 Papa Parse 处理。下载模板入口位于“我的词库”。一个 CSV 行表示一个具体词性与义项；不同义项可作为独立词条导入。需要单词聚合多义项时使用 ZIP。

```csv
word,phonetic,part_of_speech,meaning_zh,phrase,example_en,example_zh,tags
heritage,/ˈherɪtɪdʒ/,n.,遗产,cultural heritage,We should protect our cultural heritage.,我们应该保护文化遗产。,四级;传统文化
```

`word`、`meaning_zh` 必填。其他字段可省略。`tags` 使用分号 `;`、中文分号或 `|` 分隔。任何行缺少必填字段将显示错误并阻止整个文件导入，请修复后重试。文件内完全相同的词形、词性和义项行去重。CSV 无法声明媒体或考试答案别名，可在词条编辑页面补充，或使用 ZIP。

## ZIP

文件位于 ZIP 根目录，不嵌套额外外层文件夹：

```text
manifest.json
entries.json
images/heritage.png
audio/heritage-us.mp3
```

manifest 所有以下字符串字段必填；`id` 是词库来源的稳定命名空间，更新时保持一致。`tags` 可选。

```json
{
  "id": "example.author.cet4",
  "name": "四级与传统文化",
  "author": "共享者姓名",
  "version": "1.0.0",
  "language": "en",
  "source": "原创词条；请填写实际来源",
  "license": "CC0 或真实授权说明",
  "tags": ["四级", "传统文化"]
}
```

entries 为数组。每个词条必须有稳定 `id`、`word` 和至少一个 `senses`；每个义项必须有 `zh`。推荐所有义项和例句也使用稳定 id。

```json
[
  {
    "id": "heritage-n-1",
    "word": "heritage",
    "phonetic": "/ˈherɪtɪdʒ/",
    "phrase": "cultural heritage · 文化遗产",
    "tags": ["四级", "传统文化"],
    "caseSensitive": false,
    "audioUS": "audio/heritage-us.mp3",
    "audioUK": "audio/heritage-uk.mp3",
    "senses": [
      {
        "id": "heritage:legacy",
        "pos": "n.",
        "zh": "遗产",
        "acceptedZh": ["文化遗产", "传承遗产"],
        "variants": [],
        "image": "images/heritage.png",
        "examples": [
          {
            "id": "heritage:example-1",
            "en": "We should protect our cultural heritage.",
            "zh": "我们应该保护文化遗产。"
          }
        ]
      }
    ]
  }
]
```

`audio` 为通用发音；`audioUS` / `audioUK` 优先匹配发音偏好。图片关联义项，例句保存在所属义项中。每次考试对词条取第一个明确义项出一道题，以满足每词一道题的定义；建议将希望独立考察的同形异义词拆为不同稳定词条。

图片支持 PNG、JPEG、WebP、GIF；音频支持 MP3、WAV、OGG、M4A。没有任何媒体也可正常导入。不存在的合法媒体引用显示缺失媒体数量，跳过该引用；非法路径或不支持格式拒绝整个导入。不支持 SVG、HTML、可执行文件或外部 URL。

路径不得绝对、包含 `..`、`.`、反斜线、盘符或控制字符。图片引用必须指向 `images/`，音频引用必须指向 `audio/`。压缩文件最大 50 MB；解压前根据 ZIP 元数据检查单文件 10 MB、解压总量 100 MB、最多 5000 个文件；最多 10000 个词条。词形最多 200 字符，单义项中文最多 5000 字符，单词最多 30 义项。备份也受同样 ZIP 限制。

## 合并与更新

1. 优先通过来源命名空间 + 稳定词条 id 找到已导入的条目。
2. 其次只建议复用词形、词性与完整义项集合均相同的内容，不会仅凭拼写合并。
3. 完全相同内容复用原词条；内容不同时显示冲突，默认保留现有内容，也可选更新或作为不同词条。
4. 对确实不同的同形词，使用不同 id、词性或义项。在冲突预览中可以明确选择“作为不同词条”。
5. 更新只修改词库内容，保留内部词条 id；个人笔记、收藏、学习卡片与复习日志不被覆盖。历史试题使用创建时的独立快照。
6. 共享导出只有 manifest、词条与媒体，没有笔记、收藏、学习日志或考试记录。完整个人迁移请用设置中的“完整备份”。

四题型试卷：中文答案精确匹配 `zh` 或 `acceptedZh`，否则进入待确认；英文仅接受 `word` 或 `variants`。不能用简单包含关系把所有类似答案直接算对。`caseSensitive` 仅在英文拼写题为 true 时区分大小写。
