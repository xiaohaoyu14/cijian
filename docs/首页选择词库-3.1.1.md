# 首页词库选择交付说明

## 3.1.1 首页先选词库再学新词

首页新增“选择学习词库”，未选择时优先默认内置四级。选择四级/六级/SAT后，当前词条数量、剩余新词、今日进度、到期复习和开始学习入口均按该词库；仍保留明确标注的“全部词库（混合学习）”选项。学习页标明当前词库。个人考试的自选范围继续独立，考试错词回忆巩固保持原有跨库能力。

`settings.studyDeckId`保存选择。新词按该词库的关联顺序抽取、排除已有卡片；每日新词目标按当前范围的今日新学记录计算，共有词条的学习进度与今日记录共享，不建立重复卡片。切换词库不重置FSRS。

`StudySession.deckId/custom`区分队列范围，`pausedStudies`改为字符串键保存各词库各模式的独立任务。当前词库的继续入口只恢复匹配范围的队列，不会误续另一个词库。旧版无范围混合队列仍保留在原模式键下，选择全部词库可以恢复；完整备份包含选择和分库队列。若所选词库被删除，界面回退四级或首个可用库。

新增测试：按词库抽新词及到期复习、跨库独立恢复与备份、旧混合队列与已删选择回退、真实三库手机布局默认四级/切换SAT与六级/只含所选范围/切回重开恢复。生产构建已验证默认四级、全部20个新词属于四级范围、断网评分及重开保留。安卓真机本版UI未实测，不能以浏览器截图冒充真机截图。
