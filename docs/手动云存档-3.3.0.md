# 词间3.3.0：可靠存档与手动云存档试用版

## 交付范围

新增可靠存档与可配置的手动云存档。新版完整ZIP带创建时间、来源设备、应用版本、内容摘要和逐文件SHA-256；旧备份兼容读取。恢复先预览，再自动保存本机完整保护备份，保护写入失败就停止；活动数据和媒体在同一事务替换，异常一起回滚。

设置中的云存档支持连接自己的HTTPS服务、手动加密上传、历史列表、下载、预览恢复和明确删除。每次上传独立保存，满额拒绝新上传而非覆盖旧版本。下载的.cjsave也能离线导入恢复。连接信息独立存放，不进入个人备份；存档密码只在当前页面内存使用，不保存或上传。

全部原有功能、三套词库、选库、FSRS与撤销/恢复、个人考试、媒体、笔记、统计、Piper、新词即时复习、动效、分页均保留；没有清空旧数据库、改变调度或更换模型。3.3.0/versionCode15，同包名、签名与cijian-local-v1数据库，直接覆盖安装。

## 使用与部署状态

服务端已可运行并随交付提供，尚未部署到公网，没有预置公共云地址或云账号。手机云功能需要用户自己的可信HTTPS地址与连接密钥；本机测试地址/自签证书不能当作手机可用的公网服务。未配置时云功能不发起网络请求，原本地功能继续可用。

当前仅手动云备份、完整快照恢复，不提供自动备份、Wi-Fi调度、实时双向合并或账号注册/找回。默认最多10份、合计512MiB，满后保留既有数据并要求主动整理。原ZIP 50MiB、解压100MiB、单文件10MiB限制保留。云端可见时间/设备名/版本/大小等元数据，词库与个人记录由客户端加密。存档密码遗忘无法解密。

安装后可立即使用加强后的本地导出、预览恢复和保护备份。云服务部署与配置说明见[cloud/README.md](../cloud/README.md)，交付的独立服务端ZIP含server.mjs、README.md、Caddyfile.example与package.json；Node.js24运行，无npm外部依赖，无用户密钥或测试证书。

## 实现位置

- src/archive.ts：在原完整备份上添加save-manifest.json；校验文件集合、长度、SHA-256、统计与原readBackup结构，不通过不写入。
- src/vault.ts：独立cijian-vault-v1/private，保存本机身份、可选连接密钥、最近上传时间、最近一次恢复前的保护ZIP。私有连接数据不加入个人词库备份；第一版没有使用硬件密钥库。
- src/store.ts：restoreWithRecovery串行排队、校验输入、保护快照先持久化、事务替换记录与媒体；双击/旧请求按数据版本拒绝。保护写入失败保留原数据；事务中途异常显式abort，防止只替换媒体。
- src/cloud-client.ts：Web Crypto AES-256-GCM；随机16字节盐、12字节IV；PBKDF2-SHA256 600000次；头信息参与认证。HTTPS、禁止重定向、60秒请求与响应读取超时、大小限制、下载SHA校验。
- src/backup-ui.tsx：完整备份、旧版提示、恢复预览、保护备份导出/找回；云连接、密码确认、上传、列表、解密预览、文件导出和二次明确删除。恢复模式替换整个存档，不自动合并两机记录。考试快照与绝对截止时间保留，模型不上传。
- src/overview.tsx：设置表单随恢复后的实际设置同步，避免旧表单再次保存覆盖恢复偏好。
- cloud/server.mjs：连接密钥哈希映射身份，按身份隔离，独立UUID不可覆盖，幂等重试，容量检查与并发串行提交，密文/元数据临时目录写入并同步文件后原子发布，服务重启读取磁盘历史。默认仅监听127.0.0.1:8787，外部TLS交由反向代理。
- index.html / vite.config.ts：生产云连接仅允许HTTPS；仅开发服务允许明确的HTTP回环地址。未放宽APK混合内容或证书检查。
- tests/cloud-save.spec.ts：7项新增回归；scripts/verify-apk.py新增生产CSP与私钥/测试证书不入包检查。
