# 词间3.2.4：词库分页与搜索性能

## 本次变化

词库词条改为每页按需渲染50条，提供首页/上一页/下一页/末页，取消原来只能查看前300条的限制。搜索覆盖全库；搜索或切换词库回到第一页，收藏更新保留当前位置，删改后页数自动收敛。使用分页按需渲染，不是滚动虚拟列表。

词库计数、卡片状态、收藏与搜索字段使用内存索引，避免对每个词反复扫描全部卡片/笔记；索引只在数据变化时重建。到期计数与状态每15秒及回到前台时刷新，不会因为缓存一直停留在旧时间。搜索输入先更新，结果延后计算，翻页和打开详情不重复构建搜索文本。

复习档案保留原每页50条，导入预览保留每页100条及全量导入，只增加筛选缓存/延后搜索；预览中的冲突选择依旧绑定原始行索引，不因翻页或查找错位。复习学习卡片仍一张一张显示，不把整个学习队列挂载到DOM。

所有原有功能、三词库、选库、FSRS、撤销/恢复、个人考试、错词、笔记、媒体、统计、备份、Piper、3.2.2新词即时复习和3.2.3动效保留。数据库、个人记录、考试快照、FSRS参数、原生语音与依赖版本均未改变。

## 实现

- src/vocabulary-index.ts：vocabularyIndex用Map/Set索引条目、卡片、笔记、共享关联和搜索文本；vocabularyCounts用索引逐个关联统计，和内容索引分离，允许时间变化而不重做搜索文本。searchVocabulary保留原有条目顺序，同形不同义项仍以稳定条目ID区分。
- src/vocabulary.tsx：词条按50条分页加载，每页仅挂载当前词条的详情/收藏/编辑/发音按钮；useMemo缓存索引与查询，useDeferredValue优先响应键盘输入；复用原有异步媒体读取。分页是渲染策略，未把词典内容改为分库存储或删除未显示条目。
- src/reviews-ui.tsx：原50条分页继续，筛选结果缓存且延后搜索，翻页或查看记忆档案不重新过滤整表。
- src/style.css：分页区域适配手机，按钮可以换行。
- tests/vocabulary-performance.spec.ts：3项新增测试，覆盖共享词/计数/笔记/标签/顺序/时间边界、不修改原数据、真实三库全量测试卡片的卡片属性读取次数、手机首末页/全库搜索/收藏/切库。

图片仍通过原IndexedDB异步按当前义项读取并使用lazy/async解码；Piper仍在原生后台工作线程实时推理，本版未改声音模型或预打包音频。没有声称ZIP解析、图片压缩或整库持久化已经搬到Worker。

## 验证与边界

74项完整回归通过（1.5分钟）；最后将到期计数时钟与内容索引分离后，19项词库/复习/旧版兼容测试再通过（52.5秒）。生产版真实18735词验证首屏50行、末页35行、断网翻页及全库搜索、新词即时复习与重开保存；无页面异常。APK签名、模型、三词库与ABI校验通过，本版未做安卓真机流畅度或内存测试。

索引测试使用真实三套词典内容，并仅在测试内存中为18735词建立测试卡片，卡片entryId属性读取18735次，无逐词全量卡片扫描。validation/vocabulary-index-benchmark.json的毫秒数是电脑测试记录，不是安卓手机性能承诺。实际APK不包含这些测试学习记录。

生产结果见validation/vocabulary-production.json，计数和卡片仍遵守实际FSRS到期；学习/复习各产生一条真实反馈，关闭重开后为一张共用卡片、两条日志。截图deliverables/词库分页-手机末页.png是手机尺寸浏览器截图，不是真机截图。

本版没有实现连续滚动虚拟列表、数据库分块查询或全库操作后台Worker。完整备份、导入安全限制沿用原版。后续进度与Snackbar细节、更多列表（如考试历史）按实际数据量继续改进，不能把所有性能工作标为完成。
