# 第三方依赖与来源（3.0.0）

网页运行依赖：React/react-dom 19.2.0，Capacitor core/android 6.2.1，filesystem/share 6.0.4，idb 8.0.3，lucide-react 0.468.0，fflate 0.8.2，papaparse 5.5.3，ts-fsrs 6.0.0。npm完整精确版本见package-lock.json。第一版FSRS、图片与音频媒体、CSV/ZIP导入导出均已恢复；图片压缩使用浏览器Canvas，不引入在线服务。

原生：sherpa-onnx 1.13.3 AAR、ONNX Runtime（AAR内置）、Kotlin stdlib 1.9.24、AndroidX（Gradle解析）。Sherpa上游源代码与许可：[v1.13.3](https://github.com/k2-fsa/sherpa-onnx/tree/v1.13.3)，[LICENSE](https://github.com/k2-fsa/sherpa-onnx/blob/v1.13.3/LICENSE)。ONNX Runtime：[MIT许可](https://github.com/microsoft/onnxruntime/blob/main/LICENSE)。Kotlin：[Apache 2.0许可](https://github.com/JetBrains/kotlin/blob/master/license/LICENSE.txt)。

本固定版本的Piper前端还使用espeak-ng/Piper phonemize相关组件。应同时检查其GPL许可和源代码要求：[espeak-ng](https://github.com/espeak-ng/espeak-ng)，[piper-phonemize](https://github.com/rhasspy/piper-phonemize)。不能只依据Sherpa本身的Apache许可概括整个组合包。

模型：[Piper lessac-high模型卡](https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_US/lessac/high/MODEL_CARD)。该卡列明数据集与[Blizzard 2013研究许可来源](https://www.cstr.ed.ac.uk/projects/blizzard/2013/lessac_blizzard2013/license.html)。本地开发构建未执行商用授权判断，未上传商店、未公开发布。发布前应核对各部分授权，不应将仓库顶层MIT标签等同于所有语音内容的统一授权。

项目保留完整应用源代码和精确下载/校验脚本。当前APK不依赖Google Play Services、安卓系统TTS或在线语音服务。
