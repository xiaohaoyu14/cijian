# 3.2.1 交互优化第一步：答案动效与防连点

## 交付范围

用户要求先从卡片翻面动效与按钮防抖开始，随后授权直接实施。本版对应第一步：原3.2.0的全部功能、三词库、选库、FSRS、复习计划、考试、统计、笔记、媒体、备份与Piper保留。页面全局转场、全局按压/进度/Snackbar、列表虚拟化与手势属于后续步骤，本版不声称完成这些改造。

版本3.2.1/versionCode11，仅arm64-v8a，沿用包名与签名，支持覆盖安装的静态条件。

## 答案揭晓动效

- 复习或已学词回忆在查看答案后，以300ms淡入和8px轻微位移显示答案，沿用前一轮确认的方案；不是3D旋转。
- 新词仍直接显示完整讲解，不额外增加查看答案步骤。
- 揭晓前不挂载答案区域，不能通过读屏读到隐藏释义。
- 揭晓状态绑定任务、词条、位置和上次操作标识；评分换词、切换任务、撤销后不会闪现旧答案。
- 使用opacity/transform CSS动画，无JS动画循环。系统prefers-reduced-motion开启时取消此动效。

## 300ms防连点

- 首次点击立即响应，不做尾随延迟执行；300ms窗口内重复评分被忽略，不会在窗口结束后补执行到下一词。
- 四档评分共用同一把锁，交叉点“记得/忘记”等也只能写入一次。
- 异步处理尚未结束时，即使超过300ms仍不接受重复操作。
- 撤销有独立防连点，并与评分互斥；成功撤销后清除评分冷却，使用户可以正常重新评分。
- 开始/继续学习与下一批复习使用按“模式+词库/指定范围”区分的入口锁，处理中全局互斥，同一入口有300ms冷却。这样不会把暂停新词后进入复习这种正常不同操作误拦为重复点击。

## 写入保护与兼容

除了前端锁，评分在实际mutate写入前还核对任务身份、训练模式/词库、词条、队列位置、上次日志以及卡片快照。任务或卡片已经变化就拒绝该旧操作，不写日志、不推进下一词。撤销同样先核对当前游标。

新建StudySession带可选id，暂停和备份保留；旧任务无id时用完整队列及游标作为兼容身份，不清空旧任务。数据库schema/版本不变；恢复接受旧备份缺字段，新增id有类型校验。FSRS算法、参数和语音引擎均未修改。
