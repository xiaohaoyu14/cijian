# 语音提速说明

## 3.0.2 响应速度优化（2026-10-29）

用户确认3.0.1可以发声，但响应较慢。保留lessac-high音色、1.13.3引擎及无回调generate接口。页面打开后750ms、发音开启且页面可见时，后台初始化同一引擎并用a作无声预热；点击与预热共享同一个初始化Promise。关闭发音时不安排新的预热；已加载引擎仍到Activity销毁时释放，与前版一致。

恢复最多2个CPU推理线程。最近现场生成的PCM仅保留在内存，最多2MiB且不超过32词，LRU淘汰；不创建音频文件、不随备份导出、不增加预打包录音。新词仍实时生成，缓存中的重复词跳过推理直接播放；应用销毁时清空。模型本身的内存不计入2MiB缓存上限，提前加载会使这部分内存更早分配。

实测电脑CPU：热推理中位耗时单线程约345ms，双线程约189ms（heritage/access少量样本）。这只是宿主机对比，不是红米K80延迟或性能保证。结果见validation/tts-thread-benchmark.json。

验证：原41项网页回归通过，新增后台预热不自动发声/不改变学习记录测试单独通过，合计42项；Java PCM缓存的复用、字节上限、LRU、单条超限、条数上限和销毁清理测试通过，JNI契约回归通过。Release签名和模型/词库/ABI静态校验通过，仍未做本版安卓计时实测。
