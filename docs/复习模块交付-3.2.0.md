# 3.2.0 复习模块交付说明

## 当前交付

词间3.2.0，versionCode10，包名与签名沿用，仅arm64-v8a。现有3.1.1的三库、首页选库、新词、考试、统计、笔记收藏、媒体、备份及Piper功能全部保留。用户授权后，在竞品调研方案基础上仅增强复习工作流，未更换FSRS或语音引擎。

入口：“今日学习”中“开始复习”下方的“查看复习计划 →”。原“开始复习”仍可直接进入到期队列。复习计划页沿用当前所选词库，默认四级，并可切到六级、SAT或全部。

## 功能

1. 今日任务：现在到期、今天之前逾期、到期的短期学习/重学、今天稍后到期、今天已复习的不同词数及反馈次数。同词重复反馈分别计次数，但不虚增不同词数；首次讲解不当作复习。
2. 分批复习：默认20词，可选50词或全部。只限制每轮长度，积压始终显示真实剩余值。已有未完成队列不被修改，新的批量设置下一轮生效。优先到期短期学习/重学，再按到期时间从早到晚排序。未到期卡片不会为了凑数量提前加入。
3. 到期来源：按首次学习日期分为今天、昨天、2—6天、7—29天、更早、未知。分组用于解释，不是固定复习间隔。未知日期不补造历史。
4. 七天安排：按本地自然日统计当前卡片到期分布，今天包含积压。可点日期查看词条。不包括未来新增或反馈后重学所产生的额外任务，因此不是固定工作量承诺。
5. 记忆档案：初学、巩固中、较稳固、待重学；首次学习、最近反馈、复习次数、成功回忆天数、最近忘记后成功天数、复习中遗忘次数、模型稳定性及下次到期。列表每页50词，可查找。
6. 记忆估计：仅对具备有效长期复习状态/稳定性/时间的卡片，用固定版本官方model.forgettingCurve绘制从现在开始七天不复习的预计回忆概率，界面注明默认参数模型估计、非实测、非保证。记录不足时显示说明，不生成演示曲线。
7. 反馈预览：复习仍先隐藏答案；揭晓后展示四档反馈对应的预计下次时间，调用官方scheduler.preview。预览不写卡片或日志，实际评分时重新按实际时间调度。原四档含义与操作不变。
8. 本轮结束：显示本轮不同词数、四档反馈分布、当前仍到期多少、今天稍后到期多少及下一次日期，可继续下一批或查看计划。忘记的词等实际到期后再进入下一批。

## “较稳固”的透明定义

这是本软件的展示规则，不是普遍记忆定律，也不是FSRS新的调度参数：处于review状态、FSRS稳定性至少30天、最近一次忘记之后至少在3个不同本地日期回忆正确。Hard/Good/Easy都按回忆正确统计，Again重置近期成功日期计数。首次讲解不计成功回忆日，同一天重复多次仍只计一天，不要求连续签到。

标签不会停用卡片或保证永久记住。到期后仍安排复习。90%保持率仍只是原有调度目标，不是保证。选择题成绩、播放语音、浏览释义不代替回忆记录。

## 数据与兼容

- schema和IndexedDB版本不变，不清空、重算或批量改期任何旧卡片。
- settings.reviewBatch为可选字段（20/50/0=全部），旧数据默认20。
- review模式新增StudySession.reviewLogIds记录本轮真实日志ID。撤销的日志不会计入结果。
- 旧进行中队列完全保留。升级前没有本轮日志ID时，结果不补造统计；只记录了升级后后半轮时明确标注部分明细。
- 完整备份包含分批设置和本轮元数据，恢复增加可选字段校验，同时兼容旧备份缺字段。
- 遗忘和暂停均使用真实经过时间，不因暂停顺延现实时间或清空积压。
- 计划页与结束页每15秒及前后台切换时刷新时钟；点击开始时仍按当下时间重新取到期词。

## 实现位置

- src/review-plan.ts：只读任务统计、日历、来源、记忆阶段、分轮统计。
- src/reviews-ui.tsx：计划页、记忆档案、只读预测图、评分预览、本轮反馈。
- src/learning.ts：review分批与排序；保留分库暂停/恢复。
- src/scheduler.ts：原调度配置不变，增加官方预览/忘记曲线接口及本轮日志引用。
- src/study.tsx / overview.tsx / main.tsx：接入入口与复习提示，保留原模块。
- tests/review-plan.spec.ts：9项新增测试。

另外修复一次内部传参性能问题：原发音列表的每个按钮都接收整库Data，React开发模式记录性能信息时反复深度比较，导致大词库提交卡顿。现仅传发音开关、当前词条和动作；原生Piper、音色、取消逻辑均不变。CPU采样保留validation/dev-import-cpu.json，电脑开发页小词库提交流程从约33秒降至约2.8秒；这不是手机耗时承诺。
