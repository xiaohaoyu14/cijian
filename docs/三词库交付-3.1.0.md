## 实现与旧数据

`content.lock.json`保留旧四级源标识并追加两套来源、数量和SHA256；`src/builtin.ts`按源标记仅追加缺失词库。全部缺失来源校验并在草稿内导入后才统一写库，失败不留半套安装。用户手动删除过的来源不会每次启动反复重建。新包不清除原数据库、卡片、笔记或考试。签名沿用，versionCode8。

生成脚本`node scripts/prepare-builtin-dictionaries.mjs`复用实际TXT清洗器，输出public/builtin-cet6.pack和builtin-sat.pack；两者都是标准manifest/entries ZIP格式。原始TXT不修改。完整转换统计与原文件哈希见validation/builtin-conversion.json。

导入改进：每页预览100行，可翻页与搜索，冲突处理仍作用于原行，确认导入包含全部行；提交、CSV去重、首页计数及学习队列使用Map/Set避免大词库重复扫描。TXT每次最多10000有效条、文件10MiB限制，保留原CSV/ZIP和全部功能。本版没有宣称支持6GB文件；用户已澄清指的是六级词库。
